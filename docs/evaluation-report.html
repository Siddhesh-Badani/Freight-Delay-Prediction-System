Model Evaluation

Evaluation Report

Two models on a temporal split of 100,000 synthetic ocean freight shipments. Task: binary classification predicting arrival delay beyond 24 hours.

Overview

Threshold optimization targets recall ≥ 0.80. Operations teams lose more value from a missed delay (no buffer arranged, customer complaints, re-routing costs) than from a false alarm (an unnecessary buffer day). The threshold is declared before evaluating the test set, not tuned post-hoc.

Feature Definitions

All 31 features below are computed using only data available before a shipment's departure date. Rolling windows use closed='left' in pandas, meaning the window for departure date D spans [D-window, D), never including D itself.

Methodology Notes

Rolling features use closed='left' in pandas rolling windows. The window for a shipment departing on date D spans [D-window, D), never including D itself. Cold-start NaN values are filled with population-level priors: 0.20 for delay rate, 0.78 for carrier on-time rate. Models are evaluated on 2024 data only. No information from 2024 was available during training or threshold selection.
